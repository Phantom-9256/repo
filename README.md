# Orbit Portal

A calm, polished workspace dashboard for planning projects, tracking updates, and keeping your team in sync.

## Overview

Orbit Portal is a Vite + React experience designed around focused work: a lightweight inbox, project cards, quick actions, and a modern dashboard feel inspired by thoughtful productivity tools.

### Highlights

- Clean, minimal layout with a warm dashboard aesthetic
- Project and message organization with quick filtering
- Theme-aware interface with a modern purple accent palette
- Interactive gallery, notifications, and responsive cards

## Tech stack

- React 19
- Vite
- Motion for UI transitions
- Recharts for charting
- Lucide-style SVG icons

## Getting started

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
```

## Available scripts

- `npm run dev` — start the development server
- `npm run build` — build the app for production
- `npm run preview` — preview the production build locally
- `npm run lint` — run the project linter

## Project identity

This app was designed as a modern workspace portal with a strong visual identity, centered on the orbit-inspired brand mark shown above.
